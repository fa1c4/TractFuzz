# PBFuzz source and pin

- Paper: *PBFuzz: Property-Based Directed Fuzzing*, <https://arxiv.org/pdf/2512.04611>.
- Archived author artifact: [Zenodo record 20770567, version 2](https://zenodo.org/records/20770567), `artifact.zip` SHA-256 `76bccbead8b7c8bf5a5dde682eee7c7c0edbdca234dc4b0a5c95b15f85b0e6d0` (MD5 `f3c31e2805b3d1267559611c6c5aea87`). The archive is retained under ignored `results/pbfuzz/source/zenodo/`. Its Python core is PolyForm Noncommercial 1.0.0; `static_analysis/` is GPL-3.0. Its `run_experiment.sh` pins nine prepared Magma bug IDs, uses `cursor-agent`, Cursor authentication, and model `sonnet-4`.
- Current author implementation: [sgzeng/pbfuzz](https://github.com/sgzeng/pbfuzz) commit `70d0b96dce14961ca184e10d96838902bee9bae1`, built plugin tarball SHA-256 `20d13b3941bc45d54d2ab3fa2292a485119b65a91f1b081cb01045a14043fa2d`. It is a DeepSeek Harness (DSH) plugin plus Python engine, not a drop-in launch of the Zenodo Cursor artifact. DSH is pinned by `HARNESS_COMMIT` to `0.2.0-rc.2`; the plugin is licensed PolyForm Noncommercial 1.0.0.
- Author's Magma fork: [R-Fuzz/magma, `pbfuzz` branch](https://github.com/R-Fuzz/magma) commit `a6ec7b915a478306d0727f07848172500c3c4e11`. The fork does not contain the `fuzzers/pre-built/`/`BBtargets` tree described in the archived material; the current author adapter derives target locations from patched source. The separate frozen comparison binary is from this repository's `magma/` at `cec1fec38fdc510c2cb8e6ae690e738b1042cb8d`.

The user-supplied key script exposes `API_KEY`, `BASE_URL`, and `MODEL`. `scripts/run_pbfuzz_api_probe.sh` verified an OpenAI-compatible response (`deepseek-flash`, HTTP 200). The endpoint is identified in the record by SHA-256 `a34e2a4708ed1c61008a151688838dcf1c44d4e7f08054633e72ba7c0b16cfc1`; the key and URL are not committed. DSH's `llm-pi-ai` route references `API_KEY` by name and uses `openai-completions`. The model is different from the archived artifact's `sonnet-4`, so results belong to the current-author track.

The Cursor requirement belongs to the older Zenodo launcher. Its model API parameters are mediated by Cursor, and a DeepSeek API key alone cannot authenticate that CLI. The runnable DeepSeek route uses the authors' newer DSH plugin and Python PBFuzz engine. This is an explicit implementation change, so its 60-row fixed-binary results are labeled `current-author-dsh-fixed-magma-monitor` rather than described as runs of the Zenodo launcher.
