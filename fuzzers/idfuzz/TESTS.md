# Component checks

Run `scripts/test_idfuzz_boundaries.sh`, `scripts/test_idfuzz_fixture.sh`, `scripts/test_idfuzz_internal_restart.sh`, and `scripts/test_idfuzz_author_comparison.sh` after `scripts/build_idfuzz.sh` and the author fixture.

The boundary fixture checks a terminal target block, an indirect function-pointer call, two call sites sharing one target ID, a decisive byte at offset 1,050, and rejection of 17 distinct targets. The synthetic learning fixture checks that per-input dominator labels differ, reaching inputs are recorded, a checkpoint and per-seed rankings are emitted, and generated mutations record their parent and changed offsets. It then restarts the same output directory and checks that persisted observation and record counters increase. Both scripts print their artifact directory.

A byte at offset 1,050 is intentionally outside the 1,024-byte model window; the run remains valid while the model cannot select that offset. Direct target calls detect terminal blocks in this port. The indirect-call manifest records the unresolved call and contains only the callee-local chain. The pinned author artifact ran on `test/idfuzz-author-fixture.c` with 120 seeds spanning five dominator levels. The same-target LibAFLGo check imports those 120 seeds in both arms, records 24 reached seeds in each, trains only in IDFuzz mode, and checks that a fractional branch label yields a nonempty ranking for seed 074. `RESULTS.md` distinguishes live author training from its deterministic offline checkpoint replay and enumerated candidate check.

The internal restart fixture aborts once after more than 4,096 observations and uses a persistent marker to allow the restarted worker to continue. Its final run recorded one worker restart, 1,144,832 observations, and 4,976 retained records; the monitor showed an execution-counter reset while the IDFuzz observation counter continued forward. The run log is `results/idfuzz/internal-restart-test-final.log`.
