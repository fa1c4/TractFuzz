# IDFuzz method mapping

| Paper/artifact stage | LibAFLGo implementation | Boundary |
| --- | --- | --- |
| Target and dominator extraction | `passes/Analysis/IDFuzz.cpp` groups call sites by target ID, unions their direct-call paths, and takes LLVM dominators within each function | The author takes a common intersection at multiple call sites. This adaptation keeps the entry and call-site blocks of alternative paths before sampling other blocks, so a harness exercising one of several sites can still produce labels. Direct callers and dominator trees are indexed once per linked module to keep large target links tractable. Indirect calls are counted but not resolved. Up to 64 probes per target are selected; truncation is in the manifest. |
| Probes and branch encoding | `passes/AFLGoLinker/IDFuzz.cpp`; `libaflgo_targets/src/idfuzz.rs`; `runtime/idfuzz_cli.c` | Selected dominator blocks report 255; selected adjacent conditional branches can report 128 for a non-dominator edge. This is a partial port of the author's outgoing-edge branching encoder. Terminal target calls are supported by direct callback, unlike the author's missing-key-edge case. |
| Mutation history and labels | `libaflgo/src/idfuzz.rs` observer writes `idfuzz-records-v1.jsonl` | Records include full input length, first 1,024 input bytes, stable 64-bit content hash, parent hash when guided, operation and offsets, dominator and fractional branch labels, distance, direct target hit, exit kind, and model version. Records are sampled after the first 256 executions and capped at 20,000; queue admission is unchanged. The parent for ordinary MOPT mutations is unknown. |
| Training | `scripts/idfuzz_model.py` | CPU NumPy 512-hidden-unit MLP with ReLU/sigmoid, Adam and BCE; 5 epochs, learning rate 0.001, seed 1337, latest 2,048 unique records. Fixed input normalization replaces PyTorch BatchNorm. Retraining starts asynchronously every 512 retained records. The author's adaptive dataset generator, 60-second trigger, full branch encoder and PyTorch checkpoint format are not ported. |
| Gradient and fields | `scripts/idfuzz_model.py` and `libaflgo/src/idfuzz.rs` | Gradient magnitude of the first uncovered dominator label, including fractional branch labels below 1; rank comparison against two distant neighbor labels; top 20 bytes; 1D adjacent-byte clustering as a DBSCAN-like field approximation; byte enumeration plus 2/4-byte interesting values. At the deepest observed label the model selects noncritical bytes conservatively. The author's backup mode and full field mutator portfolio are not ported. |
| AFLGo control | `fuzzers/idfuzz/src/lib.rs` and `fuzzers/idfuzz_cli/src/main.rs` with `--control` | Both arms use the same binary, scheduler, distance feedback, MOPT mutation and target instrumention. `--control` disables model training and guided mutation. The CLI executor has no CmpLog/I2S tracing; both arms share that constraint. |
| Magma oracle | `scripts/idfuzz_magma.py` | Direct target hit, Magma reached (`_R`), triggered (`_T`), and crash are distinct. `PDF020` is attempted even when no directed target call survives linking. |

## Fallbacks

Before a model is ready, after model failure, when an input has no ranking, and for positions after byte 1,024, the shared MOPT stage remains active. Long inputs are counted in `idfuzz_long_inputs`. The model cannot rank bytes after position 1,023. The 16-target limit is enforced at link time; a 17th target is reported as an analysis failure. The current map supports up to 255 selected probes across the linked target and avoids the author's random 65,536-slot edge-map collisions for these probes.

The in-process runner reloads the record count, counters, and rankings in each worker after LibAFL forks its restart manager. Only workers checkpoint; the broker cannot overwrite newer counters. Checkpoints are written every 1,024 observations and at training events. A crash between checkpoints can lose the last counter increment, while the append-only record and training files remain inspectable. The post-campaign reconciliation sums monitor segments from older workers that reset counters on an internal restart.

The adaptation has no claim of bit-for-bit agreement with the author artifact. In particular, binary/fractional labels, bounded sampling, fixed normalization, field clustering, and the union of direct-call paths can change the learned rankings. Reports keep original-author checks separate from LibAFLGo runs.
